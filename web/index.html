ABOUT PLSCONVERT

Coordinate Explorer

Coordinates and PLSS lookups run in a Go WebAssembly worker. The atlas is read in small pieces; it is never uploaded. The launcher serves local application files only.

PLSS describes an area. A reverse lookup returns a representative point inside the published polygon, not a surveyed corner. Some areas have no published PLSS coverage; boundary points can have multiple matches.

The compact reader accepts exact BLM identifiers. Structured township/range input remains available in the separate plssconvert CLI.

Survey data: Bureau of Land Management. Overview geography: Natural Earth, public domain. Map renderer: Leaflet. Map outlines are generalized for display; selected PLSS polygons retain their source coordinates.

BLM data are not legal land surveys. This project is not affiliated with or endorsed by BLM. No online street or satellite tiles are requested.
